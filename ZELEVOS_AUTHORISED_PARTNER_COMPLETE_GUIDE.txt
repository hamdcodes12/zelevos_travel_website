3. CUSTOMER BOOKING ME YEH REFERRAL CODE KAISE KAAM KARTA HAI?
--------------------------------------------------------------------------------
Ab dekhiye commission kaise banta hai:

1. Customer website par aata hai aur koi bhi Holiday Package choose karta hai (e.g. Kashmir Tour ₹45,000).
2. Customer [Book Package / Customise] click karta hai.
3. Checkout Modal open hota hai jahan customer apna Name, Email, Phone bharta hai.
4. Usi Checkout form me ek option hota hai:
   --> "Partner Referral Code (Optional)"
5. Agar customer partner ke referral link se aaya tha, toh code AUTOMATICALLY bhar jayega.
   Ya customer manually apna code (e.g. ZELVOYAG42) wahan type kar sakta hai.
6. Customer payment complete karta hai.
7. System backend me turant:
   - Booking ko us Partner ID se link kar deta hai.
   - Commission calculate karta hai: (₹45,000 ka 5% = ₹2,250).
   - "commissions" table me entry save kar deta hai (Status: PENDING).
